# 都道府県キャノン

47都道府県を、実寸大のまま大砲で撃ち出して飛距離を競う、物理演算ブラウザゲーム。

- 県を選ぶ → 角度ゲージをタップで止める → パワーゲージをタップで止める → 発射
- 県の形と大きさは実際の比率のまま。重さは面積のルートに比例し、重心(回転の中心)は県庁所在地(★)
- 大砲の火薬は全県共通。北海道だけ大きい大砲で、火薬が3.2倍
- 空気抵抗あり。風を受ける幅は、実際の形の幅と同じ面積の円の幅を 1:3 で混ぜたもの
- 県は発射角と同じだけ傾いた状態で撃ち出される(0°で北が上)
- 記録は、発射位置から止まった県の一番前の端までの距離(大きい県は図体のぶん有利)。実寸のkm表示で、県ごとの自己ベストは端末に保存
- 結果画面から Twitter に記録を投稿できる(発射速度と飛距離。発射速度は最初の1秒間の平均の速さ)
- PC(クリック / スペースキー)・スマホ(タップ)対応
- BGMと効果音つき(効果音はブラウザ内で合成)。右下のボタンで消音できる

## 地球モード

県の選択画面のボタンで切り替え。自己ベストは通常モードと別に記録する。

- 地球は半径6,371kmの球。重力は中心に向かい、距離の2乗に反比例(地表で9.8m/s²)
- 大気は上空ほど薄くなる本物の密度(スケールハイト8.5km)。県は厚さ1km・密度2,700kg/m³の岩の板として空気抵抗を計算するので、実際はほとんど効かない
- 画面は約452倍速のタイムラプス。地球から離れるほど、さらに早送りする
- 大砲のルールは通常モードと同じ(火薬は全県共通、北海道だけ3.2倍)で、火薬の量だけ地球用。平均的な県がパワー90%前後で重力を振り切るくらい
- 結果は物理の計算そのまま
  - 一度も地面に触れずに地球を1周したら「○○は地球の第二の衛星となった」
  - 重力を振り切ったら(または遠地点が月の軌道より遠くなったら)「○○は宇宙の彼方へ旅立って行った」
  - それ以外は落下。記録は地面に沿って測った距離
- 秒速数kmの激突なので、着地ではほとんど弾まない(反発係数0.05)
- 一度大気圏の外(高度120km以上)に出て、また大気に入ってくると、隕石のように燃える演出(見た目と音だけ。燃えている間はスローモーション)

## 真・長崎県 / 真・沖縄県

通常モードで長崎県・沖縄県を一度撃つと解禁される(端末に記録)。

- 面積5km²以上の島(各23島)を、実際の地図どおりの配置でまとめて撃ち出す
- 着地するまでは1つの塊として飛び、地面にぶつかる直前に島ごとに分解する。各島はその瞬間の塊の速さと回転を引き継ぐ
- 分解後は島ごとに独立して動き、島どうしもぶつかる
- 記録は、一番遠くまで行った島の前の端までの距離。結果画面に島の名前が出る
- 島の名前は、地図上の位置から割り当てたもので、小さな島は名前が付かないことがある

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | ゲーム本体(画面・入力・描画) |
| `physics.js` | 物理コア(Matter.js 0.20.0 を CDN から読み込み) |
| `shapes.js` | 都道府県の形データ(本土のみ・km単位、滋賀県は琵琶湖を除く)と、真・長崎県/真・沖縄県の島データ |

| `bgm.mp3` | BGM「ひとりぼっちの宇宙紀行」 |

## 公開(GitHub Pages)

1. このフォルダの中身をリポジトリ直下に置いて push
2. リポジトリの Settings → Pages で、Branch を `main` / `/ (root)` にして Save

## 形データの出典

[dataofjapan/land](https://github.com/dataofjapan/land) の `japan.geojson`(国土数値情報ベース)を、各県の本土ポリゴンだけ取り出して簡略化したもの。離島は含まない(真・長崎県/真・沖縄県を除く)。

琵琶湖の形は [Natural Earth](https://www.naturalearthdata.com/)(パブリックドメイン)の湖データを使用。
